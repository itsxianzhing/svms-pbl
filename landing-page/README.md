# SVMS — Sports Venue Management System

SVMS is a sports venue management platform designed to help venue owners and administrators organize bookings, manage courts, monitor payments, and understand business performance through one centralized system.

This repository contains the **SVMS marketing landing page**, built to introduce the platform, explain its value, showcase its capabilities, and encourage venue owners to request a product demo.

**Live Website:** https://svms.itsxianzhing.tech  
**Interactive Prototype:** https://dashboard-svms.itsxianzhing.tech/
**Google AI Studio:** https://ai.studio/apps/e2b779ba-d975-4a64-ad0b-944055e9204d

---

## 1. Landing Page Overview

The landing page guides visitors through the SVMS product story, starting with the problems of traditional venue management and ending with a clear call to action.

The primary target audience is sports venue owners and administrators, particularly badminton courts, futsal fields, and other sports facilities.

### Main Objectives

- Introduce SVMS and its value proposition.
- Explain the operational problems faced by sports venue owners.
- Demonstrate how SVMS centralizes venue operations.
- Present the platform's features and benefits.
- Explain the platform workflow.
- Encourage visitors to request a product demonstration.

Customers select a venue, choose a court, select an available time slot, and submit a booking.

**03. Kelola Operasional**

Owners and administrators monitor bookings, daily schedules, and payment statuses through the SVMS dashboard.

**04. Pantau Performa Bisnis**

Owners use dashboard summaries to understand booking trends, revenue, and court utilization.

## 8. Running Locally

### Prerequisites

- Node.js.
- npm.
- Gemini API key, if Gemini-powered functionality is enabled.

### Installation

1. Clone the repository.

```bash
git clone <repository-url>
cd <project-directory>
```

2. Install dependencies.

```bash
npm install
```

3. Configure environment variables.

Create a `.env.local` file in the project root:

```env
GEMINI_API_KEY=your_gemini_api_key
```

Only configure this variable if the application actually uses Gemini API functionality. Never commit API keys or other secrets to the repository.

4. Start the development server.

```bash
npm run dev
```

5. Open the local development URL displayed in the terminal.

### Production Build

```bash
npm run build
```

### Local Preview

```bash
npm run preview
```
